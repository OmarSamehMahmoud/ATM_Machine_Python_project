# ATM_Machine_Python_project
ATM_Machine_using_python_code

1. The system first asks the user to enter this account number then click enter.

2. If the account number is not defined by system, the system would show an error message then result.

3. After the user enter the correct account number ,the system would ask the user to enter the password ,the user would have three trials to enter his password.Each time the password in incorrect ,the system would ask to reenter the password showing to him a message that incorrect.

4. If the password is entered incorrect 3 times ,the system would locked the account forever.And the user would be able to enter his account. If the user tried to enter a locked account,the system would show a message that the account is locked, please go to the branch.

5. If the user enter a valid password ,the system will give him the following options:

  --> Cash Withdraw.
  
  --> Balance Inquiry.
  
  --> Password Change.
  
  --> Fawry Service.
  
  --> Exit.
